# Projeto AG2

Projeto desenvolvido para a **Avaliação Global 2 (AG2)**, com o objetivo de
treinar, avaliar e disponibilizar um modelo de aprendizado de máquina capaz de
classificar o canal de vendas de clientes de um distribuidor atacadista.
